# Tool Window 验收

至少验证以下可观察行为：

1. 一个按钮只打开、聚焦或关闭同 ID 的窗口；不会依赖全局 active session 猜目标。
2. 同侧拖动改变 tab 顺序，刷新后顺序仍由布局描述恢复。
3. 上、下、左、右、编辑区和独立窗口只在允许时高亮；非法 drop 不改变布局。
4. popout 被阻止或关闭时，面板回到上一次有效停靠区，且不会丢失内容状态。
5. 插件停用后按钮、面板、事件、定时器和 popup 引用全部释放。
6. 组件在主文档和 popout 文档中都使用正确的 `ownerDocument`；菜单和浮层仍使用共享 FloatingSurface。
7. 桌面、窄桌面、移动单面板均能访问已交付功能，长标题和长内容不会撑出视口。
