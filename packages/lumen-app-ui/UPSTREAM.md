# Lumen source provenance

This independent package was extracted from the Lumen directory of
[hbar-ui](https://github.com/He-Jiahui/hbar-ui) at commit
`25b900206f13d27c54c6dc974d965e3e7b4b71b0`. Its MIT license is preserved in
[LICENSE](LICENSE). The upstream MUI monorepo is not required to install, build
or test this package. MUI is an ordinary declared peer used by three adapters.

The hbar workspace maintains this source snapshot and consumes its public
exports. The standalone repository export retains the source, license, tests,
build configuration and provenance; repository publication is a separate step.
