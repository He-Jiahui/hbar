# 页面设计：外壳、工程会话导航与起始状态

上级：[UI 总计划](index.md)。依赖：[总体架构](architecture.md)、[组件整治](component-remediation.md)。任务范围 R1、R2。

## 1. AppShell 与滚动区域

以 `HbarAppUiAppShell` 为唯一生产外壳，沿用 workbench 公开入口。扩展受控插槽：sidebar、header、main、tool、overlay；组合根提供内容，Shell 只负责布局与可访问区域。

根节点占满可用视口；从根到滚动节点的 flex 子项均设置 min-inline/block-size: 0。主区去掉目前的统一大 padding 和嵌套 Surface，页内自己决定阅读宽度。body 不承担消息、工程树或表单滚动。

| 区域         | 宽高行为                                    | 滚动所有者        | 固定内容                      |
| ------------ | ------------------------------------------- | ----------------- | ----------------------------- |
| AppSidebar   | 默认 17.5rem；受布局描述约束，可调整        | 工程树 body       | 顶部品牌/操作、底部状态/设置  |
| PageHeader   | 内容自适应；常规单行                        | 不单独滚动        | 返回/菜单、标题、当前页面操作 |
| Session 主区 | flex: 1；阅读区与输入区统一 max-inline-size | Timeline          | Composer 与 UsageSummary      |
| SessionTool  | 宽屏默认 24rem；按断点变换呈现              | ToolPane body     | title、toolbar、footer        |
| 管理页       | 占 main；保留应用侧栏                       | 当前表单/图表内容 | 页头、分类导航、保存条        |

图标使用 md；紧凑元信息使用 sm/xs。界面只用一层必要分隔线，禁止 main→Surface→Spotlight 连续套壳。

## 2. 侧栏结构

```text
品牌 hbar                                      收起
＋ 新建会话
⌘ 命令                                      Ctrl K

工程                                         打开工程
▾ 项目名称                            行内更多操作
    当前会话标题…                  运行/待审批摘要
    其他会话…                              最近时间
▸ 项目名称
                  工程树独立滚动

● 服务端：已连接 / 连接中 / 已断开
状态                                             设置
```

底部不放打开工程、扩展和其他不相关按钮。断线时可以在状态行附近显示重连操作；状态数据本身保持只读。正常连接时不显示无意义的刷新/重连按钮。

### 工程与会话行

- 工程作为一级、session 作为二级；折叠不改变当前会话。工程名称溢出省略，tooltip 展示完整名称/路径。
- 会话行展示标题和一个紧凑状态区；待审批优先于运行，再显示最近时间。状态变化不改变行宽和按钮位置。
- 工程内“新建会话”明确使用该 workspaceId；更多菜单中的操作只针对原行，不冒泡触发选择。
- 点击 session 运行 `app.setSession`，成功后才更新活动页面；同名会话用工程和辅助标识区分，真实 key 使用稳定 ID。
- 当前 `workspace.list/session.list` 分页继续复用，默认每页 100；展开时加载，列表尾显示加载更多/重试。虚拟化按展开后的可见节点执行，不能截断记录冒充完整列表。
- 工程删除、会话归档或列表刷新后选中项失效，主区显示失效状态与可执行入口；不自动切换到其他人的会话。

首轮不新增未经支持的全历史搜索功能。命令入口负责可发现操作；若以后增加目录搜索，必须具备服务端有界查询契约，不能用只过滤已加载第一页的控件冒充全局搜索。

## 3. 新建/打开流程

| 起点                     | 呈现                               | 执行与成功结果                                        | 失败行为                                   |
| ------------------------ | ---------------------------------- | ----------------------------------------------------- | ------------------------------------------ |
| 无工程，点击打开工程     | 平台目录选择/Host 路径表单         | 使用 `workspace.open`；目录查询更新后进入该工程空状态 | 表单显示路径原因；保留输入                 |
| 有当前工程，点击新建会话 | 小型会话创建表单；默认继承工程设置 | 执行 `session.create`，成功再 `app.setSession`        | 原会话保持；创建表单可重试，不能重复建会话 |
| 无当前工程，点击新建会话 | 同一表单先选工程                   | 创建与选择顺序相同                                    | 不跳命令目录要求用户手填内部 ID            |
| 工程行内新建             | 同一表单固定该工程                 | 明确显示目标工程，可选标题                            | 原列表/页面不因行内点击改变                |

Tauri 本地路径选择与远程 Host 路径不能混为一谈。Web 场景使用已有资源端口支持的选择模式；缺少能力时显示手动输入 Host 路径及校验，不伪造本地目录授权。

## 4. 起始页与错误页

- **已连接、无工程**：简短标题和打开工程主操作；无演示工程、无大指标卡。
- **有工程、无会话**：展示当前工程名称与新建会话操作。
- **已连接、未选会话**：提示从侧栏选择或新建；保留所有全局入口。
- **连接中**：区域级 loading，不清空已有目录；新的写操作禁用并说明状态。
- **断线**：保留已加载的会话和草稿，明确数据可能过期；错误反馈与重连靠近连接状态。
- **无权限/目标失效**：提示具体目标和恢复入口，不把服务器错误原文作为整个页面标题。

这些状态都由宿主提供 typed labels/content；不在 AppShell 中硬编码业务文案。

## 5. 页头与全局管理页

会话页头只展示一次会话标题，可附工程名称和简短运行状态。右侧顺序固定：文件、监控、子 Agent、目标与计划、会话设置。去掉竖排文字按钮；图标提供 tooltip/aria-label，窄屏收进“会话工具”菜单。

管理页左侧显示返回会话与当前页面标题；右侧只放本页操作。进入设置/状态不改变 active sessionId，返回恢复原上下文。没有原会话时返回 Session 空态。

## 6. 断点与键盘

| 宽度     | 左侧栏          | 右工具           | 设置/状态                            |
| -------- | --------------- | ---------------- | ------------------------------------ |
| ≥80rem   | 常驻，可收起    | 分栏             | 完整分类＋内容                       |
| 64–80rem | 常驻，可收起    | 右侧 drawer      | 完整分类＋内容                       |
| 48–64rem | 菜单打开 drawer | 右侧 drawer      | 可折叠分类栏                         |
| <48rem   | 菜单打开 drawer | 单面板页面＋返回 | 分类选择＋内容，保持同一 scope/group |

侧栏抽屉与工具抽屉互斥覆盖，打开后焦点进入所属区域；选择会话后收起侧栏。`Escape` 先关闭最上层临时界面，不能取消 Run。`Ctrl/Cmd+K` 使用现有命令入口；模态表单活动时不得让背景页面响应快捷键。

## 7. 验收场景

0/1/100/101 个记录、重复 ID、失效选择、同名会话、长中英文名称；工程行内操作不触发选中；导航失败/连续快速切换；两窗口状态隔离；刷新布局恢复；320 宽度下可访问全部入口。逐屏查看侧栏占比和内容，不以“无横向滚动”代替视觉验收。
