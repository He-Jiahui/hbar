参考布局再次目视对照 `D:/Git/cc-haha/docs/images/app/en/session-dark.webp` 与 `settings-general.webp`。hbar 保留其稳定的侧栏→主工作区→按需工具空间、设置分类栏、紧凑页头和就近操作关系；按既定产品决定使用更高信息密度的 JetBrains 风格，不迁入 Scheduled、Skills Market、Pet、顶部多标签等无关业务。

## 3. 行为门禁

- 全仓 ESLint（Node 8 GB heap）、TypeScript 与 Bun tests：397 个测试、3148 个断言、零失败，覆盖 124 个文件。默认 `bun run check` 的 ESLint 进程在约 4 GB 达到 V8 heap limit；改用同一 ESLint 配置和 8 GB heap 后通过，其后 typecheck 和全部 tests 分别通过。
- Web production build：2392 modules；CSS 217.69 kB。构建边界确认旧 WorkbenchShell、catalog、fixtures、Kernel、Storage、TUI 和未采用的自由停靠模型不进入 Web 生产图。
- Playwright：6/6。四个离线 locale/viewport 场景、一个 101 会话真实 Host 容量场景和一个完整真实 Host 场景；真实流程遍历工程/会话原目标行菜单、创建与重命名、四类工具、设置、Provider、Extensions、状态三分区、命令三步流、发送/审批/取消/Usage 更新。
- 每个实质样式切片均运行 flow guard；用户可见 TSX 按范围运行 content-contract 与 icon-scale guard。最终生产截图在各切片修复后重新生成并人工查看。
- 参考差异属于产品决定：hbar 使用工程→会话二级树、状态中心、命令目录和会话工具；不复制 cc-haha 的额外业务入口或顶部工作区标签。

## 4. 不纳入 R6.3 完成声明的事项

- Tauri 实窗、系统 DPI、标题栏、原生文件选择和窄窗属于 R6.4。2026-09-20 已用当前代码成功编译并启动 debug 窗口，但 Windows 会话处于 LockApp/LogonUI 锁屏，Computer Use 按强制规则停止，未取得有效实窗截图。
- 主应用当前显式使用 dark 主题；Prompt 与表单控件已有 light 独立验证，但不能据此宣称整页 system/light 主题完成。该差距仍归 R1.1。
- 长历史滚动、流式快速切换和断线恢复仍归 R3.5，不因会话目录容量验证而提前关闭。R2.4 已以 0/1/100/101、服务端分页、侧栏滚动、选择稳定、原目标行菜单和真实重命名完成；R2.5 已以真实 Host 创建、幂等重试、桌面/窄屏截图和可读目标控件完成；R2.7 已以 schema、v1 迁移、坏数据回退、受控尺寸几何和六项生产 Playwright 回归完成。
