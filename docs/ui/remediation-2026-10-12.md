# 2026-10-12 UI 架构整改

本轮按附件的第 0～4 步推进，生产链路为 Web → app-react → Lumen。
代码在 `codex/ui-remediation` 隔离工作树中逐项验证和提交，原工作区已有修改保留。
早期 [组件整治计划](component-remediation.md) 中的 hbar-app-ui 名称描述历史实现，
当前生产 UI 使用 `@lumen/app-ui`，兼容目录与预览不在生产 workspace 中。

## 已交付的结构调整

- 生产入口不加载 ReactBits 参考主题，参考路由仅在开发模式动态加载。
  已删除无引用的 `recharts`、`@xyflow/react` 依赖。
- Lumen 位于独立源码包 `packages/lumen-app-ui`，保留许可证与上游来源记录。
  仓库已移除 MUI fork 子模块依赖，MUI 通过版本化公开依赖提供。
- 侧栏常驻新建、搜索、项目/会话树、通知和设置；次要入口归入更多菜单。
  扩展与技能在设置中访问。
- 状态中心按系统、运行、用量、诊断组织；原入口归到相应分区。
  会话面板用同一个停靠实例切换活动、监控、代理与目标/计划。
- 会话页按头部、历史、恢复提示和输入区拆分，区域各自订阅所需数据。
  外壳拆成侧栏模型、项目树、侧栏底部和工具区；保留持久 pane 的实例归属。
- `app-runtime` 统一给出 Composer 的可提交、可取消、锁定和阻止原因。
  Goal 与 Plan 保持独立意图，草稿和操作回执继续由原 runtime 管理。
- Lumen 的主题变量使用 `--lumen-*`；宿主阅读、语法和文字角色在
  `app-react/src/theme-bridge.css` 映射一次。旧 theme-store CSS 写入函数已移除。
- Lumen 根 API 收敛为基础控件和工作台组合。付费墙、账单、认证和看板在
  显式目录/组件族入口中；工作台和目录 CSS 分别构建，不由宿主加载完整目录。
- 宿主样式和滚动/焦点查询使用公开 `data-lumen-part`，不再引用内部
  `.lumen-*` 类名。契约与 Stylelint 入口见 [样式契约](../ui-style-contracts.md)。

## 验证范围与仍在推进的项目

上述切片已经分别通过严格 TypeScript、定向 ESLint、相关单位/React 测试和构建。
真实宿主的浏览器检查覆盖中英文、桌面与 390/320 窄屏的会话面板、草稿保留、
侧栏导航、输入与停止、主题选择及历史分页。独立 Lumen CSS 另验证明暗主题、
根字体缩放与五档图标尺寸，不依赖宿主样式补偿。

设计刻度、三断点与内部容器、typed message catalog 和中文术语正在后续独立
切片中实现。输入区其余提示进入会话面板的共享登记也在推进；本页不把这些
尚未完成的项目计为交付。

此前较宽的旧浏览器集合有失败案例，包括旧入口定位、流式夹具不完整与启动
诊断断言；其中桌面 Find 启动诊断已在拆分前版本复现。通过定向新检查不等于
全部旧 E2E 已通过，后续修复和最终验证须单独记录。
