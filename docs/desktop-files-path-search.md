# Files: All files path search

Reference evidence: cc-haha's published `D:/Git/cc-haha/docs/images/app/en/workspace-changes.webp` shows the search control inside Files above its list, but that particular frame is in Changed mode. The All-mode behavior is established by `desktop/src/components/workspace/WorkspacePanel.tsx` and the deep-directory cases in `WorkspacePanel.test.tsx`: path results can be opened without expanding ancestors, and returning from preview retains the query. The reference repository was read-only.

hbar previously filtered only already-loaded tree nodes. The existing Host `file.find` command now backs the same All-files search field with a 250 ms debounce and a 100-result limit. It searches case-insensitive workspace-relative **file paths**, not contents or directory names. A result shows its file name and parent path and opens through the existing file-preview command; returning preserves the query and any unsaved document draft. Clearing restores the lazy tree. Search has distinct loading, no-match, error/retry and truncated states, with no silent fallback to loaded nodes. In-flight work is aborted on query change, panel close, target change and mode switch; late results are ignored by panel/workspace/query identity. Keyboard Arrow Up/Down, Home/End, Enter and Escape work in the search field without intercepting IME composition.

The copy is supplied by the web Host in Chinese and English. Search/clear/refresh use the shared semantic `sm` icon tier and stay in a single flexible toolbar at 320 px; the result list flows with long file names and parent paths. The screenshot layout is not reproduced with absolute coordinates or fixed content heights.

Verification: `tests/file-workspace-search.test.ts` exercises unopened paths, preview/back/draft, no match, error/retry, truncation, superseded response and close/rebind isolation. `e2e/file-workspace-tree.spec.ts` ran against a real temporary Host in en-US and zh-CN (2/2), including 1440/1024/390/320 widths, two same-named files in different parents, keyboard End/Enter, Escape, preview/back, original tree navigation and unsaved draft. Production screenshots were inspected at `artifacts/file-search/search-en-US-1440.png` and `artifacts/file-search/search-zh-CN-320.png`. This is not content search and does not add a Search chats contract.
