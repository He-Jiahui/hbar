# UI 中文术语

Web 工作台的中文文案统一使用以下译法。实体名称、协议字段、斜杠命令、模型供应商名称和英文界面保持其稳定原文；中文说明只翻译用户可读的部分。

| English term                | 中文用法 | 说明                                                                                                                                                |
| --------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Host                        | 宿主     | 指运行 hbar Host 服务并提供工作区、存储和插件能力的运行环境。写作“宿主连接”“当前宿主”“宿主全局设置”。                                               |
| Run                         | 运行     | 指一次会话执行。写作“运行状态”“运行记录”“停止运行”；作为标识使用时写作“运行编号”。                                                                  |
| Agent                       | 代理     | 指由模型驱动、可执行任务的代理。写作“代理计划”“代理活动”“代理审批”；child agent 写作“子代理”，parent agent 写作“主代理”。不在同一短语里重复“代理”。 |
| Token（模型用量）           | 词元     | 指模型输入、输出、上下文、预算、速率和计费中的 token。写作“输入词元”“词元预算”“每秒词元数”。                                                        |
| Token（认证或操作系统凭据） | 令牌     | 指认证凭据或 Windows access token。按语境写作“认证令牌”“访问令牌”；不译为模型词元。                                                                 |
| Token（设计系统）           | 设计令牌 | 指主题中的语义设计变量。写作“主题令牌覆盖”或“设计令牌分组”。                                                                                        |

斜杠命令 `/agent`、`/stop` 等属于可执行命令，必须原样呈现；它们周围的说明可以翻译。协议 ID、枚举值、动态用户输入与产品或供应商名称也不能因术语统一而改写。英文界面的文案继续保留自然英文。
