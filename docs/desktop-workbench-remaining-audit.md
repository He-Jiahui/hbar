This is not a claim that tool calls carry agent IDs.
2. **P2 — Browser activity/preview (clearly narrower than the reference native Browser).** If desired, first use `browser.status` for a session-owned list with availability and origin-policy error states, then `browser.snapshot` or safe bounded screenshot for an explicit selected `{sessionId,contextId,pageId}`. Do not silently start a new context, navigate, send picked content, or render returned text/URL as trusted HTML. Embedded browsing, picker and native lifecycle require separate Host/desktop security design.
3. **P3 — Terminal and Team are backend-led initiatives.** Define capability/ownership/cleanup for PTY and a genuine event-sourced Team snapshot before adding chrome. Neither belongs in a visual-only migration commit.
