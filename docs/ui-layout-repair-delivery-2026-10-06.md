# hbar UI 布局、控件与桌面交付记录

日期：2026-10-06。对应用户确认的 22 项布局与控件修复方案，以及后续“工具标签固定长度”和文本省略审计。

## 交付行为

- 生产入口的 41 个原 `LumenSelect` 调用位置已迁移到组件化 PopupSelect 或对应的 ToggleGroup；动态 schema 使用明确的 renderer 描述，不根据中文标签推断类型。
- 设置页思考等级采用单选 toggle，模型支持的等级采用多选 toggle。会话与空会话输入区的滑杆保持不变。继承、关闭思考、未传可选参数仍是不同的领域值；不能把 `max` 当作 `off/none`。
- 项目、父 session、subagent 保持三级导航。subagent 的配置与策略、保存草稿及权限语义没有因控件迁移而改写。
- 工具动作标签使用同一个 `7.5rem` 固定宽度槽，默认 16px 根字号下为 120 CSS px。图标与文字在槽内对齐，正文保留伸缩空间，窄屏允许正文换到下一行，不靠固定行高裁剪内容。
- 下拉、菜单及添加操作接入共享 Lumen 浮层。弹层脱离工作台局部裁剪，统一背景、视口约束、外点关闭、嵌套关系与焦点恢复。

固定标签实现见 [session-message.css](../packages/app-react/src/session-message.css)。文本省略完整分类见 [文本溢出审计](ui-text-overflow-audit-2026-10-06.md)，不将所有集合容量限制误报为文本缺陷。

## 验收中发现并修复的附加问题

- `b2d4d329`：工具动作标签长度不同导致正文起点变化；统一固定槽宽。
- `16fc12f1`：窄屏回归验证同一固定槽宽与自然换行、容器内几何及不重叠，不再错误要求所有窄屏行都保持单行高度。
- `fd30cf65`：导航、项目位置、项目错误及 Goal 完整内容有明确恢复入口；Git 保留短 hash 指标并通过已有详情显示完整 hash。
- `b6dc3fdb`：原生添加菜单原先被聊天内容遮挡；迁移到 body portal 的共享 anchored 表面，关闭时内容隐藏且 inert，但 Goal slot 的状态保留。
- Lumen `b863abfb8e`：命令搜索的 Escape 先由查询控件清空非空内容，再交由统一协调器关闭空查询表面；Tab trap 与外点捕获仍由共享组件负责。
- `2e0f44c5`：首次访问懒加载设置分类时，外层 Suspense 会连导航一起卸载。将等待边界限制在内容区，保留导航与入口焦点。
- `91da6b3c`：测试通过实际 trigger 的 `aria-controls` 关联 portal，按稳定领域 ID 检查选择，不再使用原生 select API 或假设菜单是行的 DOM 后代。

移动端设置返回恢复仍可见的工具入口，桌面端因入口随内容卸载而回到命名会话区域；两种路径均验证原会话名及草稿，不用 class 特判丢弃有效的焦点目标。

原生验收使用独立临时 profile、项目、数据库、WebView 数据及本地 mock 模型，不改真实供应商或会话。实际验证：首次发送仅创建一个 session，模型/思考等级与 Goal/Plan 一起进入原 Run；审批恢复不丢草稿；添加附件、聊天搜索、Markdown/Mermaid/源码/文件搜索/技能、供应商上下文设置与命令输出/Copy 可用；默认及最小 CSS 工作台尺寸无重叠/横向溢出；隐藏、后台通知去重、桌面退出后 Host 存活与独立 SDK 取消通过。

Windows 关闭存在系统确认框：选择“否”隐藏到托盘，选择“是”退出服务。测试通过 computer-use 观察并仅对隔离 release 窗口选择“否”。这不是 Rust 死锁。通知测试在确认实际隐藏后才启动 mock run，避免任务在可见窗口等待确认期间完成而不产生后台原生通知。原生命令与人工确认等待都有明确超时；成功或失败都会清理本次拥有的临时进程和数据。未改动用户的正在运行的开发实例。

125% / 150% 采用 WebView2 的进程级 device scale factor，并核对真实 `devicePixelRatio`；不改变 Windows 显示设置，也不声称验证了操作系统多显示器 DPI 切换。为可比较的交互流程，临时窗口按缩放比例保持相同的 1440×960 / 900×600 CSS 工作台尺寸。系统通知验证的是原生接收与重复抑制，不声称系统通知 UI 一定显示或用户已读。

全仓质量门禁仍有既有失败：`bun run typecheck` 报旧 CLI/Web/Storage 及测试契约错误；`bun run lint` 在 8 GiB 堆上限下内存耗尽。全仓 `check` 不标记绿色。完整省略审计属于静态可达性清单，不证明所有 44 个 CSS 截断声明在所有字体/数据量/视口下都已运行验收；具体残留边界见文本审计文档。
