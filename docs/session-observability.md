# 会话观测与统计

会话统计由 Host 从会话 SQLite 的持久事件查询。请求账本、压缩记录和工具结算记录是事实来源，不再复制计费流水。工具测量通过公开 `ToolActivity` 契约随 `message.committed` 或 `tool.sequence_result` 一起提交，仍由既有日志恢复、会话删除和分页机制管理。

统计范围：整个 Session；一次用户输入及随后自动续跑，直到下一次用户输入；两次成功压缩之间的上下文窗口。压缩失败不打开新窗口，压缩请求及其费用属于被关闭的窗口。

技能目录曝光不代表使用。`skill` / `skill_read` 实际读到的技能 ID、名称、资源和修订进入工具结算记录；同一 Run 与修订的说明页全部读取后，记录一次完整加载。重复页不增加使用次数，引用资源读取另计。完整加载表示指令已提供给模型，不能证明模型执行了每条指令。

本地文件工具记录实际读取文本行数；图片的文本行数缺失。成功写入后按有界 diff 记录补丁片段数量和涉及的新增、删除文本行，同一行多段变化只计一行。统计为累计操作量，后续重写会继续累加，不等于最终 Git diff。大型差异使用有界算法的保守片段划分。第三方工具未提供的测量保持缺失，不从输出文案猜测。

终端统计依赖工具声明的 `command` presentation 和 Host 测量的执行时间，待审批时间不计入命令耗时。成功率使用成功 /（成功 + 失败）；拒绝、取消、意外中断、未知结果分别展示，不伪装为失败或成功。费用使用请求发生时保存的价格快照，未知价格不当作零费用。
