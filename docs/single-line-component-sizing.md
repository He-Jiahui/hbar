# 单行组件尺寸与溢出契约

按钮、标签、闭合选择器、状态、标签页和单行条目由完整文字、图标、gap、padding 与边框决定尺寸。禁止固定文字宽度、`text-overflow: ellipsis`、以隐藏溢出裁切文字，或因文本变长而在组件内部换行。标题与可访问名称提供辅助信息，不能代替可见完整文本。

文字按钮允许最小点击目标；图标按钮、状态点和缩略图保留语义尺寸 token。最小点击区域不等于把文本框锁成固定宽高。

受限工作台里，容器拥有溢出。输入工具栏采用单行横向滚动，发送 / 停止保持在滚动区外。滚动区本身可聚焦，禁用按钮的文字仍可用方向键查看。标签页与单行数据行采用同样的局部滚动边界，页面本身不横向溢出。允许外层在明确断点重组整个组件，不能把一个标签拆成几行。

Markdown 正文、编辑器、说明段落和包含标题加说明的多行选项维持正常阅读流；它们不应继承单行控件规则。分页、虚拟化与 Host 内容容量是独立契约，不因移除视觉省略而取消。

输入栏实现由 Lumen 的 `LumenPromptComposer`、app-react 的项目上下文与闭合选择器共同承担。[浏览器回归](../e2e/single-line-controls.spec.ts)检查中英文、明暗主题、320 / 390 / 900 / 1024 宽度、加载 / 离线 / 错误、完整生成分支名、长标签和 200% 文字缩放；断言真实文本 Range 边界、单行行高、滚动可用性与主动作可见性。[真实 Host 回归](../e2e/composer-control-density.spec.ts)还保留审批中的原草稿与未发送边界。

Lumen 文字按钮默认不可压缩、单行，垂直 padding 随字号计算。工作台 / 文件标签页按完整标题自然占宽，由标签条滚动；侧栏树由导航窗格滚动，移动端当前会话标题由自己的单行容器滚动。闭合选择器、附件文件标签与搜索入口采用同一规则。带描述的多行选项明确保留正常文字流。[真实导航回归](../e2e/single-line-navigation.spec.ts)检查长会话名、桌面标签页、移动端标题、侧栏名称和功能按钮的完整内容及页面边界；受控组件回归还覆盖 0 / 1 / 7 / 32 / 33 条记录与原目标回调。

[旧省略清单](ui-text-overflow-audit-2026-10-06.md)记录此前的实现与辅助标题补全方式。本契约取代其中允许依赖 tooltip 或详情弥补单行文字裁切的规则；历史清单不代表现行验收标准。

折叠工具 / 思考行的标签与摘要按全文自然占宽，右侧结果状态不可压缩，行内阅读区域承担溢出。聚焦行后可用左右方向键滚动，Enter / Space 继续只负责展开。思考的选定首行 / 最新行、常规工具说明和错误首行不再因 160 / 72 字符的显示长度而添加省略号。工具参数抽取仍受 4,000 code point / 8,192 UTF-16 unit 的处理预算约束；超过提取预算时明确标注原文入口，复制来源保持原始输入 / 输出。提取预算不等同于用 CSS 隐藏可见标签。

任务、Agent、文件树、排队消息和模型列表的单行字段保持完整文字，由列表承担横向滚动。引用路径由可聚焦的单行区域滚动，行号保留独立空间；编辑器内的文件提及保持完整原子标签，正常输入仍可多行编辑。搜索结果明确包含标题、工作区、时间和正文片段，正文允许自然换行，角色 / 时间 / 工作区标签保持单行。排队消息的 Host 预览预算仍有效，发生真实截取时显示“可编辑查看全文”的宿主文案，不附加视觉省略号。[数据与提及回归](../e2e/single-line-controls.spec.ts)覆盖 0 / 1 / 100 条任务、Agent 的 50 条边界、完整路径、模型选择和提及的撤销 / 恢复。

共用页面标题、工具面板标题、设置列表标题、表单 label、复选框和开关的名称也遵守单行契约；辅助说明继续允许多行。菜单中的普通动作、复制 / 展开 / 恢复按钮和设置导航不再通过局部 `white-space: normal` 覆盖共用按钮规则。目录管理中的名称使用局部阅读区域，优先级、移除和确认动作保持各自完整的点击区域。

`packages/app-react/src` 中保留的正常换行规则限于搜索正文、包含说明的模型 / 权限 / 位置选项、扩展说明、批注正文、设置恢复说明、工作区名称加路径的多行卡片及正文中的文件链接；这些内容不属于单行按钮或标签。布局适配层也必须遵守本契约，不能重新引入高优先级的省略或裁切规则。
