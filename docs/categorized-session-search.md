# 会话入口与分类搜索

“新建会话”和“搜索聊天”位于侧栏“工程与会话”标题下方。入口保持可见，工程列表独立滚动。
全局新建会话先选择工作区；工程行内的新建动作使用该工程。创建和搜索导航均保留原会话的未发送草稿。

## 搜索来源

| 分类         | 索引内容                                                | 选择后的定位                                     |
| ------------ | ------------------------------------------------------- | ------------------------------------------------ |
| 全部         | 下列五类来源                                            | 每个结果分别标记来源并定位                       |
| 会话标题     | 当前会话标题，重命名立即生效                            | 最近的助手输出；没有助手输出时定位最近的用户消息 |
| 对话内容     | 已保存的用户、助手文本                                  | 匹配消息；可见文本内定位到关键词                 |
| 修改的文件名 | 成功修改结果中的 `details.path`                         | 对应的编辑调用                                   |
| 补丁内容     | `details.before/after` 中发生变化的行及其上下文         | 对应的编辑调用与可见匹配内容                     |
| 工具命令     | 工具名、声明的 `commandField`；兼容历史 `shell.command` | 对应的工具调用与可见命令匹配内容                 |

工具结果使用同一会话中对应助手调用的消息 ID、块索引和 call ID 定位。
已完成的折叠活动组先展开，再展开目标调用。标题定位使用 Host 返回的准确输出消息 ID，
即使该输出已不在 Web 初始加载的 60 条历史中也能按需加载。
定位请求绑定工作区、会话和页签实例；完成后消耗请求，保留实际阅读锚点。

思考块、任意工具参数、凭据、普通工具输出以及失败的文件修改不进入这些索引。
归档会话不出现在普通搜索中。隐藏工程中的结果仍可搜索，打开后展示该工程。

## 容量与升级

`session.search` 命令版本为 2；Host 与 Web/Client 必须一起升级。
来源参数为 `all/title/conversation/file/patch/tool`。单次查询最多 160 个 UTF-16 单元，
Host 最多返回 50 个会话、每个会话最多 10 个匹配；Web 最多展示 50 个独立结果。
同一会话的不同消息或来源有各自的结果 ID，不会合并成一个错误的跳转目标。
超出显示容量、索引尚未完成或达到 4,000 候选扫描上限时给出相应提示。

旧版文本索引升级时仅重建可恢复的搜索投影，保留原始消息和 JSONL。
搜索索引按有界后台步骤更新；界面支持取消、过期响应隔离、断线恢复和输入法组合状态。
定位沿用最多 1,000 条消息、17 次旧历史分页和单次读取 12 秒的边界。
无法恢复目标时显示既有阅读位置不可用提示。
