# 会话工具与全局页面

导航以内容的归属决定展示区域。目标与计划、子 Agent、用量监控、文件和会话活动使用会话工具区域；会话设置保留其会话目标与现有设置入口。运行看板、排期、提示词模板、首次配置、通知中心，以及状态中心和全局设置使用工作台主内容页面。

全局页面覆盖会话内容，右侧工具暂时隐藏；页面之间切换不改变所选会话，也不会重建会话草稿。返回会话恢复原来仍存在的工具。明确选择另一个会话时，以新选择为准。通知打开原始会话或排期时保留通知中记录的目标，目标不存在时在原页面显示失败反馈。

主页面类型由 `@hbar/contracts/commands/surfaces` 的公开枚举定义。Web outlet、运行时 presentation、导航命令摘要和键盘归属都遵守这个契约。全局页面没有侧栏工具入口，也不参与会话工具宽度或停靠布局保存。工作区相关页面使用明确选中的工作区；没有工作区时显示配置入口，不借用一个会话作为目标。

页面内容使用正常 flex 流，返回入口与标题位于固定的结构头部，正文在自身内容区域滚动。窄屏打开页面后收起工程与会话侧栏，焦点进入具名页面区域；返回时恢复可用的原始入口或会话区域。中英文标题与返回文案由 Web 宿主提供。

参考：https://pro.reactbits.dev/docs/app-ui/app-shell/app-shell-4 — 主内容与会话上下文工具分开归属，沿用现有工作台描述文件。

参考：https://pro.reactbits.dev/docs/app-ui/notifications — 通知中心作为全局内容入口，通知状态与原始目标由 Host/runtime 提供。
