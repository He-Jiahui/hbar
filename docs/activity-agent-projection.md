# Activity Agent projection

The session-owned Activity tool now has independent confirmed Run and child-Agent groups. `activityWorkspace.refreshAgents` / `loadMoreAgents` read only the public plugin-owned `agent.list` records for the captured parent Session. They do not create an Agent, parse `agent.created` in Storage/UI, or classify every child Session as an Agent.

Agent reads use pages of 50, at most 200 displayed rows and four sequential pages per refresh, with a shared 12-second cancellation deadline. Refresh aims to retain the previously loaded prefix count; the Agent API has no revision-bound cursor, so this is a checked bounded listing, not an atomic snapshot. Duplicate/foreign records and non-progressing cursors fail explicitly. Confirmed rows stay visible on read errors with stale/error feedback. Closing or hiding the source aborts reads and releases its projection.

Existing non-token sidebar activity/visibility hints are reused, coalesced for 300ms, and read only the visible Activity tool. A hint during an active read schedules one follow-up. Run hints retain the prior loaded count through the existing revision-validated pages (up to ten pages); each accepted prefix is published, not a single atomic replacement. Agent hints publish the checked listing when its refresh finishes. No background polling or whole-history subscription is added.

An Activity Agent row reuses `agentChild.open`. The source must be the visible parent Activity panel and contain the captured Agent record; the existing path re-reads `agent.result.get`, validates parent/child/workspace/archived state and source-tab incarnation, and only then opens the actual child Session tab. Back retains the existing ephemeral parent relation; closing/reopening a parent or reloading does not invent a return target. A stale displayed record never replaces the Host identity check.

Runtime verification: `tests/activity-workspace-runtime.test.ts` and `tests/agent-child-navigation.test.ts` cover public parent paging, retained rows on failed reads, visible hint coalescing, hidden late reads, foreign parents, and Activity child open/Back. The prior Run and Agent-navigation regressions remain included. UI/reference validation is recorded in the subsequent desktop Activity delivery note. Parent-running aggregation in the global sidebar, Team, shell background jobs, tool-use correlation and `/agent` semantic changes are not implemented by this projection.
